# AI Hospital Management System

A modern, responsive, and feature-rich Hospital Management System built with React and Vite.

## Features

- **Dashboard**: Real-time overview of hospital statistics.
- **Patient Management**: Complete record-keeping for patients.
- **Doctor Directory**: Manage medical staff and schedules.
- **Appointment Scheduling**: Seamless booking and management of patient visits.
- **Billing System**: Integrated invoicing and payment tracking.
- **Symptom Checker**: AI-powered preliminary diagnostic tool.
- **Ambulance Tracking**: Real-time location monitoring for emergency services.
- **Nearby Help**: Locate pharmacies and clinics in the vicinity.
- **Prescriptions**: Digital prescription management.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: CSS3 (Modern, Responsive)
- **State Management**: LocalStorage for persistence
- **Icons**: SVG / Lucide Icons

## Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/mohit2003116/ai-hospital-managemnent-system.git
    ```
2.  **Install dependencies**:
    ```bash
    npm install
    ```
3.  **Run the development server**:
    ```bash
    npm run dev
    ```
